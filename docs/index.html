🚀Passo a passo — do zero ao primeiro resultado

💡 Calma, é simples. Se você sabe copiar e colar, você sabe usar. Nada quebra se você errar — é só digitar de novo.
1

Tenha o Claude Code

O plugin roda dentro do Claude Code — a ferramenta de IA da Anthropic que funciona no seu computador (terminal, app ou na web). Se ainda não tem, baixe em claude.com/claude-code. Já tem? Pula pro passo 2.

2

Instale o plugin (só uma vez)

Dentro do Claude Code, digite estes dois comandos — um de cada vez, apertando Enter:

# 1) adiciona a "loja" de onde o plugin vem /plugin marketplace add andersonmeloseo/andersonmelo-seo # 2) instala o plugin /plugin install andersonmelo-seo@andersonmelo-seo
✅ Pronto. Não precisa repetir — fica instalado.
3

Faça sua primeira auditoria

Digite o comando abaixo, trocando pelo endereço do seu site:

/seo auditoria https://seusite.com.br
👉 O plugin visita seu site, analisa, e devolve uma nota de 0 a 100 + uma lista do que arrumar, em ordem de prioridade.

Exemplo real: rodamos /seo auditoria https://andersonmeloseo.com.br e ele respondeu, entre outras coisas: "Health Score 80/100 · a home tem 3 elementos <main> (deveria ter 1) · falta o arquivo llms.txt · sem cabeçalhos de segurança". Achados de verdade, com o que fazer em cada um.

4

Entenda o resultado (sem decoreba)

A resposta vem organizada assim:

  • Health Score — a nota geral do SEO do site. Quanto mais alta, melhor.
  • Critical / High / Medium / Low — a ordem pra arrumar. Comece pelos Critical.
  • Cada item vem com por que importa e o que fazer.
Não entendeu um termo? É só perguntar: "o que significa <termo> que apareceu na auditoria?" — ele explica.
5

Fale em português normal

Você não precisa decorar comando. Pode simplesmente perguntar, que ele escolhe a ferramenta certa sozinho:

por que meu site não aparece no Google? como faço pra aparecer no ChatGPT? meu concorrente é o site X — o que ele tem que eu não tenho?

🧠O que ele sabe fazer

1 cérebro central (/seo) + 10 especialistas + 5 auditores. Você não precisa saber qual é qual — só descreva o que quer.

🔍 Diagnosticar (achar o que está errado)

seo-auditoria

Raio-x do site inteiro com nota de 0 a 100 e plano priorizado.

seo-topical

Plano de conteúdo pra dominar um assunto (quais artigos criar e em que ordem).

seo-on-page

Como otimizar uma página específica + roteiro de conteúdo.

seo-geo

Ser citado por IA: ChatGPT, Perplexity, Google AI Overviews, Gemini.

seo-backlinks

Perfil de links e autoridade — com método grátis, sem ferramenta paga.

🏗️ Construir (montar do jeito certo)

seo-programmatic

Criar muitas páginas (ex.: por cidade) sem cair em conteúdo raso/penalidade.

seo-schema

Os "dados estruturados" que o Google lê pra entender seu site.

seo-semantic-html

Estrutura técnica + velocidade (Core Web Vitals) + acessibilidade.

seo-local-rank-and-rent

SEO local (Google Maps) + modelo de gerar leads (rank-and-rent).

seo-hreflang

Site em vários idiomas/países sem o Google se confundir.

❓Perguntas de quem está começando

Preciso saber SEO?

Não. O plugin explica os termos, mostra o que está errado e diz o que arrumar — em ordem de prioridade. Você aprende usando.

Preciso saber programar?

Não. Copiar e colar um comando é o suficiente. E se você errar, nada quebra — é só digitar de novo.

O que é "Claude Code"?

É a ferramenta de IA da Anthropic que roda no seu computador. O andersonmelo-seo é um "complemento" (plugin) que se instala dentro dela. Baixe em claude.com/claude-code.

É grátis?

Sim, o plugin é grátis e de código aberto (licença MIT). O Claude Code tem os planos dele à parte.

Preciso de Ahrefs / Semrush (ferramentas pagas)?

Não para começar. Ele trabalha com o que está disponível e com dados gratuitos (Search Console, Bing Webmaster). Se você tiver ferramenta paga, dá pra colar os dados e ele fica mais preciso.

Funciona pro meu tipo de site?

Sim — WordPress, loja virtual, blog, site de serviço local, landing page. A metodologia é a mesma.

O plugin inventa número quando não sabe?

Não — essa é a regra principal dele. Sem dado real, ele te diz o método e o que coletar, em vez de chutar uma métrica.

Quer ajuda de gente de verdade no seu SEO?

SEO programático, Local SEO, rank-and-rent e GEO — Brasil, EUA e Espanha.
