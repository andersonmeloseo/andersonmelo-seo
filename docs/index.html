🧭O que é

Um plugin de metodologia, não de ferramenta. Transforma o Claude Code num consultor de SEO, GEO e AEO que diagnostica um site em 9 camadas e constrói o que falta — topical maps, páginas programáticas, schema, HTML5 semântico. Sem depender de API paga para começar.

Modo Execução — há dado ou URL acessível. Analisa de verdade, cita evidência, quantifica.
Modo Framework — falta dado. Entrega o método e o que coletar — e nunca apresenta estimativa como medição.

🧠O que vem dentro

1 orquestrador (/seo) + 10 sub-skills + 5 subagents. Chame direto ou só descreva o problema — o orquestrador roteia.

🔍 Diagnosticar

seo-auditoria

Auditoria completa em 9 camadas → health score 0-100 + plano priorizado.

seo-topical

Topical authority: mapa de tópicos entity-first, clusters, cobertura de intenção.

seo-on-page

Otimização on-page de uma URL + content brief competitivo.

seo-geo

Citabilidade por IA: AI Overviews, ChatGPT, Perplexity, Gemini, Claude.

seo-backlinks

Perfil de links e autoridade — free-tier (GSC/Bing/Common Crawl) ou pago.

🏗️ Construir

seo-programmatic

Páginas em escala, data-driven, com travas anti-thin / near-duplicate.

seo-schema

Schema/JSON-LD @graph, knowledge graph, integridade de ratings.

seo-semantic-html

HTML5 semântico + Core Web Vitals na marcação + Lighthouse 100 + a11y.

seo-local-rank-and-rent

Local SEO (GBP, NAP, citações) + playbook rank-and-rent.

seo-hreflang

SEO internacional: auditoria e geração de hreflang (return tags, x-default).

⚙️ Subagents de auditoria — a seo-auditoria dispara cinco especialistas em paralelo para sites grandes: seo-auditor-tecnico · seo-auditor-conteudo · seo-auditor-schema · seo-auditor-geo · seo-auditor-arquitetura.

🍳Receitas

🏙️ Lançar um portal programático de cidades

  1. /seo topical "<seu serviço>" — entidade central e mapa.
  2. /seo programmatic plano — confirma o dataset que diferencia cada página + padrão de URL.
  3. /seo schema … — @graph de LocalBusiness por página.

🤖 Fazer um conteúdo ser citado pela IA

  1. /seo on-page <url> — resposta direta no topo, entidades nomeadas, estrutura de passagem.
  2. /seo schema <url> — speakable, FAQ, autor com sameAs.
  3. /seo geo <url> — llms.txt, AI crawlers, citabilidade.

🔗 Avaliar autoridade sem ferramenta paga

  1. /seo backlinks seudominio.com — em Modo Framework te diz o que coletar de graça (GSC, Bing Webmaster, Common Crawl).
  2. Cole o export → ele quantifica em Modo Execução.

❓Perguntas frequentes

Preciso de API paga (Ahrefs, Semrush)?

Não para começar. As skills operam com coleta de página e dados gratuitos (GSC, Bing Webmaster, Common Crawl). Dados pagos, quando você os cola, deixam a análise mais precisa.

Funciona em inglês?

As skills são escritas em português, mas a metodologia é universal — o Claude executa no idioma em que você fala com ele.

Vai conflitar com outro plugin de SEO?

Via /plugin não — as skills ficam isoladas por namespace. Só o install manual sobrescreve skills de mesmo nome.

É grátis mesmo?

Sim. Licença MIT, código aberto. Use, modifique, contribua.

O plugin inventa números?

Não — é o princípio central. Sem dado real, opera em Modo Framework e te diz o que coletar.
